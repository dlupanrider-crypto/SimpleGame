# 午间俱乐部

一个无需服务器的 Chrome 局域网小游戏插件，包含你画我猜和乌龟汤。

## 安装

每位玩家打开 Chrome 的 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择本项目文件夹。点击扩展图标进入游戏大厅。

## 联机

1. 房主创建游戏，点击「邀请」，把邀请连接码发给一位同事。
2. 同事点击「加入房间」，粘贴邀请连接码并生成回应码，将回应码发回房主。
3. 房主粘贴回应码并点击「完成连接」。每增加一位同事，房主重新点击「邀请」重复以上步骤。
4. 房主开始游戏。你画我猜首轮由房主画，随后按加入顺序轮流作画；猜对的玩家和画手各得 1 分，分数在当前房间内累计。当前画手可查看题目、手动判断猜测或结束本轮。乌龟汤由房主主持并回答问题。

你画我猜会随机选择预设题目，画手也可以点击「自定义题目」输入 1–20 个字。更换题目会清空当前画布，猜测者只会看到题目字数。

乌龟汤由房主从预设题目开始，也可以点击「自定义乌龟汤」填写标题、汤面和汤底。开始后只有房主能看到汤底，点击「揭晓汤底」后才会同步给其他人。自定义内容保存在当前房间内。

使用 WebRTC 直接连接，连接码包含局域网地址；需要玩家间网络可互通。公司网络隔离、防火墙或浏览器策略可能阻止连接。没有配置公网中转服务，也不保证跨网络连接。房主关闭页面后房间结束，游戏状态只保存在内存中。
