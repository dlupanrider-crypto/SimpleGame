# 午间俱乐部

一个无需服务器的 Chrome 局域网小游戏插件，包含你画我猜、乌龟汤和谁是卧底。

## 安装

每位玩家打开 Chrome 的 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择本项目文件夹。点击扩展图标进入游戏大厅。

## 联机

1. A 在在线大厅点击「邀请新成员」，把连接码发给 B；B 点击「加入大厅」并将生成的回应码发给 A，A 粘贴回应码完成连接。
2. B 可以用同样方法邀请 C。新成员会尝试与其他在线成员建立直连；连不通时可通过仍在线的成员转发。
连接完成后，邀请弹窗会显示对应成员已连接；若长时间未建立直连，会提示重新交换连接码。

3. 任意成员创建游戏房间，在房间内的「邀请在线搭子」中选择成员。对方接受后加入房间。
4. 房主开始游戏。你画我猜首轮由房主画，随后按加入顺序轮流作画；猜对的玩家和画手各得 1 分，分数在当前房间内累计。当前画手可查看题目、手动判断猜测或结束本轮。乌龟汤由房主主持并回答问题。

你画我猜会随机选择预设题目，画手也可以点击「自定义题目」输入 1–20 个字。更换题目会清空当前画布，猜测者只会看到题目字数。

乌龟汤由房主从预设题目开始，也可以点击「自定义乌龟汤」填写标题、汤面和汤底。开始后只有房主的游戏界面能看到汤底，点击「揭晓汤底」后其他人的游戏界面才会显示。自定义内容保存在房主本机的「我的汤谱」中。

使用 WebRTC 连接，连接码可能包含局域网连接信息；需要玩家间网络可互通。公司网络隔离、防火墙或浏览器策略可能阻止连接。没有配置公网中转服务，也不保证跨网络连接。大厅连接由插件后台维护，游戏房间仍在页面中运行：房主关闭页面后当前游戏断开，房间会从在线列表中消失。通过在线大厅邀请的游戏消息使用 ECDH 协商密钥和 AES-GCM 加密；身份公钥尚无独立认证，无法抵御主动替换公钥的中间人。旧版手动房间连接不使用这套转发加密。

游戏页面关闭时，如果大厅后台仍在线，收到的游戏邀请会触发浏览器通知；点击通知可打开页面处理邀请。邀请有效期为 60 秒。

房主创建的房间会保存在自己的浏览器里，可以在大厅点击「恢复我的房间」。房间内由房主点击「切换游戏」，已经连接的玩家会一起切换；关闭页面后需要重新邀请。恢复房间会从等待状态开始，使用在线大厅加入的访客拥有本机固定身份，可关联之前的得分。创建新房间会替换此前保存的房间。

房主可以点击「销毁房间」并确认，通知已连接成员返回大厅，并删除本机保存的房间和得分。如果所有人都离线，大厅不能自行重新发现成员，需要至少一组成员重新交换连接码。

## 谁是卧底

创建「谁是卧底」房间，邀请至少 3 名大厅搭子（共 4 人及以上），由房主开始。每人看到自己的词语，依次描述；之后每位存活玩家选择一名其他玩家投票。平票时重新描述并投票；投出卧底则平民获胜，卧底存活且剩余人数不超过 2 人时卧底获胜。中途有存活玩家离开时本局结束，可重新开始。

词库包含 140 余组词对。房主负责随机分配并保存本局身份，其他玩家只接收自己的词语；游戏结束后公开答案。房主客户端负责判定，因此不能防止房主通过开发工具查看身份。本游戏不支持在进行中恢复局面，恢复房间后需重新开始。所有玩家应重新加载新版插件。
