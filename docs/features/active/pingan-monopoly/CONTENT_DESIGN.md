# 职场热梗与吐槽内容设计

> 实施状态：首版草稿已可试玩，本文是目标设计，实际完成范围和差异以 [执行计划](PLAN.md) 为准。

特性：`pingan-monopoly`；状态：`active`；更新：2026-10-28。

本设计扩展 [大富翁方案](DESIGN.md)。素材草稿保存在 [workplace-humor.zh-CN.0.1.0-draft.json](content/workplace-humor.zh-CN.0.1.0-draft.json)：包括身份状态、金句、黑话、职场话术、甩锅话术、废话文学和阴阳怪气，黑话附人话翻译。当前 76 条是内容素材，不是已经实现的游戏事件或正式发布的玩法包。

## 游戏中的呈现

- **事件卡**：触发时展示卡片标题、段子、明确效果和结果；用 `content_id` 引用文案，再由玩法包独立配置数值。例如「班味入骨」增加被发现风险；「卡急马」可以选择维持体面或冒险；「工位坐禅」降低风险。被叫住或被安排临时任务会导致撤离失败。具体数值须通过对局测试确定。
- **黑话翻译挑战**：展示黑话、选项或让玩家判断人话；使用独立题目 ID 和正确答案，答对降低风险，跳过或答错不惩罚。不能用未定义的自由文本相等判断替代题目设计。
- **吐槽卡**：画饼、甩锅和打压话术作为对不合理现象的虚构讽刺，不把这些话直接作为系统对玩家的评价。可显示“拆穿话术”的解释；轻量版默认关闭较尖锐内容，由房主创建房间时明确选择开启。
- **闲聊彩蛋**：金句及废话文学以无数值的、可关闭的游戏内提示呈现；不伪装成玩家发送的消息，也不强行代替玩家聊天。

内容示例的语气应轻松、调侃现象而非攻击个人或岗位。用户给出的素材按原意保存，敏感话术标记为可选；显示前仍需要内容审核和产品确认。事件不能声称是中国平安的真实政策、组织安排或真实员工经历。

## 数据与版本

素材条目使用稳定 ID、分类、文案、标签、受众和默认开关；黑话另存 `plain_language`。`audience=optional` 的条目不在默认牌池中，用户可自主开启。素材库不包含可执行代码，也不自行改变风险、体面或位置：每个可玩的事件由版本化玩法包显式声明 `content_id`、出现条件、权重、效果类型和参数。页面展示文本与执行效果必须引用同一事件定义，防止出现“文案写降低风险、实际增加风险”。

示例结构（示意，非已发布数据）：

```json
{
  "event_id": "event-work-status-001",
  "content_id": "work_status-001",
  "weight": 1,
  "effect": {"type": "risk_delta", "amount": 1},
  "effect_label": "被发现风险 +1"
}
```

扩展采用内置只读内容包，运行时不执行文案、不作为 HTML 插入；游戏应使用 DOM `textContent` 或现有安全转义。校验 ID 唯一、分类与效果白名单、数值范围、引用存在性及默认过滤。素材与玩法分别版本化；发布的玩法快照明确引用素材包 ID、版本与内容哈希，保存启用的内容选项。即使只是文字变化也创建新的内容版本，既有版本不原地覆盖；已开始的对局继续使用冻结内容。新版本应可在创建房间时选择；缺少相同内容时拒绝加入并说明版本不一致。

`0.1.0-draft` 允许审阅期修改，不作为已发布不可变版本。词条来源为用户提供素材；如后续加入外部来源，要记录来源和授权范围。内容开关仅决定新对局牌池，不修改已经开始的房间。
