# 准点撤离：长局办公楼地图设计

> 实施状态：首版草稿已可试玩，本文是目标设计，实际完成范围和差异以 [执行计划](PLAN.md) 为准。

特性 ID：`pingan-monopoly`；版本：`office-escape@1.0.0` 草案；状态：`active`；更新：2026-10-29。

## 目标与范围

以先前确认的微缩办公室效果图为视觉方向，将原单层 5×5 地图扩展成**三层、每层 7×7 的虚构办公楼**，支持固定 4 个席位，真人不足由机器人补足。默认 40 个公共轮次上限，目标是让仍在行动的玩家有机会经历 30 轮以上的路线规划、事件和区域切换。

30 轮以上是设计目标与地图容量，**不是每局保证的最低时长**：玩家可能被叫住而提前失败，也可能采用较短路线提前撤离。真实平均时长、成功率和机器人节奏尚未通过实测，不能把估算当作验收结果。

“轮”指所有仍在行动的席位各完成一次回合，包含机器人。真人、机器人已成功或失败后，后续轮次跳过；所有席位结束时对局提前结算。固定四席，不在开局后补新玩家或替换席位。

## 地图：三个相连的 7×7 区域

坐标以每层左上角为 `(1,1)`，上下左右移动，`#` 是墙，`.` 是普通通道。玩家共享地图但彼此不阻挡。每层中央和边缘保留多个岔路，具体家具可在不改变通行关系的前提下调整；风险、事件、安静点和墙均用图标与文字区分，不能仅靠颜色。

| 图例 | 含义 |
| --- | --- |
| S | 起始工位，四席同格出发 |
| C | 路线检查点，第一次经过即完成，无须额外停回合 |
| T | 楼梯，须先完成本层检查点；转层消耗 1 步 |
| E | 出口或电梯终点，须先完成本层检查点 |
| H | 高危节点，每次进入风险 +1 |
| ? | 事件节点，主动停下时抽卡；经过不抽 |
| Q | 安静节点，主动停下时风险 -1；每人每节点每局最多一次 |

## 移动与长局节奏

每个行动回合掷一个公平六面骰：点数 1～3 允许移动 **1 步**，4～6 允许移动 **最多 2 步**。玩家可在额度内提前停止，但至少移动一步；上下楼转换计一步。经过检查点立即记录完成；进入已开放终点时立即成功。高危风险、终点和事件处理顺序沿用 [玩法规格](GAMEPLAY_SPEC.md)。

三层无事件、每次均采用最短路时，经过检查点到电梯最短 **57 步**，到出口最短 **56 步**（含两次转层）；无墙外路径、传送或额外移动时绝对最少 28 次行动。骰子折算的期望额度为每次 1.5 步，简单估算约 37～38 次行动；受掷骰波动、提前停止、事件、失败和玩家策略影响，实际不保证达到此值。40 轮上限及地图内容需要模拟、机器人策略和真人对局调平。

每人经过的节点都会触发进入效果；落点安静节点每人每局仅首次降低风险。高危节点可绕行；玩家可以预览下一次行动路径及其可见风险，但不能预见牌堆。事件只能在事件节点主动停下时触发，不能通过短步停留在原格反复抽卡。事件造成额外移动时，同一行动最多额外触发一次落点事件，防止连锁。

风险维持 0～4，达到 4 立即失败；从容休整节点提供有限风险恢复。任务、会议或被叫住的强制失败事件保留用户明确的失败条件。三张直接失败事件在长局中可能过于严苛，发布前必须根据抽卡频率与模拟结果调平；如修改牌池、权重或规则，需在发布前固定版本，已发布后使用新版本，不得静默改旧包。

## 事件、机器人和体验节奏

每层有不同的事件池标签：第一层偏工位与热梗，第二层偏会议、黑话和“就五分钟”，第三层偏大厅与撤离。沿用共享去重牌堆和敏感内容开关，具体事件须声明适用区域；当前区域无可用牌时返回“平静经过”，不消耗其他区域牌。玩家看到的卡片要明确效果。至少 30 张事件仍是首版内容目标，不代表素材库里的 76 条已全部变成可玩事件。

机器人从公开信息中计算合法路径，不预知骰子和牌堆；选择路线时权衡距离、可见风险与剩余轮数，且有有限随机性，不能一直原地或绕圈。机器人参与同样的风险、事件和排名，动作有简短可跳过的展示；不参与需要外部服务的内容。真人掉线不会自动被机器人替代。

## 独立界面与版本

进入对局后使用独立游戏界面，主区域只显示当前玩家所在层地图；侧栏显示四席身份、轮次、当前行动者、各自所处楼层和事件日志。提供楼层总览和路线预览，允许查看已知地图但不曝光其他玩家未公开的信息。跨楼层时有清楚的动画和文字提示，动画可关闭。事件、胜负、断线以及风险提示不能仅靠颜色。

此地图取代尚未发布的单层首版草案，保持 `office-escape@1.0.0` 为**未发布提案**。发布前冻结地图、规则、事件、机器人策略与内容开关，并纳入玩法包哈希及协议兼容检查。未来发布后新增地图或改动回合规则需新版本；已发布旧包继续可选，进行中的对局版本不变。

## 实施前验证

- 对三个网格做 BFS：起点到检查点、检查点到楼梯/终点均连通；验证两次转层与两个出口，检查至少两条可行路线。
- 覆盖 40 轮、四席轮转、真人 1/2/3/4 人补位、机器人不读隐藏状态、无效路径及消息幂等、事件牌堆、安静节点限次、风险与终点顺序。
- 进行大量策略模拟，报告 30 轮以上的比例、完成/失败率、强制失败卡影响和四席平均用时；不达体验目标时调整提案。
- 进行窄屏、无障碍、断线，以及至少两台设备真实插件联机实测；真实设备验收和内容审核完成前文档保持 planned/active，不标记完成。
