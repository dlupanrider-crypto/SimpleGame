# 准点撤离：执行与验收记录

状态：开发中，首版草稿可试玩；未完成正式验收。更新：2026-10-29。

## 已实现

- 游戏大厅入口、独立游戏页面、三层 7×7 地图和四席（1～4 真人，剩余席位由机器人补足）。
- 房主主持回合；骰子显示真实点数。真人可预览、撤回并一次确认相邻路线，提前看到风险，房主校验整条路径后才执行；同时支持检查点、楼梯、安静点、事件、终点和 40 轮结算，共 30 张草稿事件。
- 机器人使用公开地图规划路线；非房主断线后等待，房主可将当前离线玩家判为退出失败。
- 邀请及房主握手检查草稿版本 ID；房主隐藏未抽取牌堆，拒绝无权或过期动作。
- 本地打包 Three.js 0.160.1（许可见 `vendor/three/LICENSE`）；独立办公楼地图按规则生成三层和可点击路径；提供键盘可用的平面地图及 WebGL 降级。
- 正在按概念图迭代：暖色城市背景、顶部四席、底部操作栏、楼层与风险面板，局部光影、地面贴图、风险及休息区图形、人物和家具素材及移动过渡；楼层缩略图显示玩家位置。工位已接入本地三维模型，窗口增加城市景观，会议室与边缘低墙由三维几何体绘制。素材来源见 `assets/escape/ASSETS.md`。[实际扩展截图](assets/office-escape-architecture-eval.png)。

## 待完成

- 当前仅有 `office-escape@1.0.0-draft.2` 一种草稿，尚无版本选择器、规范化内容哈希和旧版本包保留机制，不得视为正式冻结版本。路线消息已变化，所有联机成员需使用相同草稿版本。
- 补充事件文案和多区域牌池、视觉素材、完整结算排序与并列呈现；机器人当前仍逐步移动，需继续统一其动作和展示。
- 完成真实多设备联机、断线重连、版本不兼容、长局体验与平衡验收。当前不支持重连或房主迁移。
- 视觉还原仍在进行：当前人物及部分家具为面向镜头的 2D 素材，建筑主体为程序化几何场景；与概念图的细致立体模型、完整布景和动画仍有差距，需要继续完善并以真实画面验收。
- 用户验收后将整个目录迁往 `docs/archive/features/年份/`，更新文档索引；未完成验收前保留在 active。

## 自动验证

- `node tests/escape.cjs`：规则、四席、30 张事件及 100 局机器人模拟。
- `node tests/escape-ui.cjs`：大厅建房、独立界面、掷骰、移动、机器人、窄屏和离开。
- `node tests/escape-extension.cjs`：需安装 Playwright Chromium，以真实扩展加载方式验证资源和游戏流程；缺少 Chromium 时跳过。
- `node tests/escape-models.cjs`：工位模型加载后在场景重绘时保持完整，资源异常回退由 `escape-assets-fallback.cjs` 验证。
- `node tests/escape-design-ui.cjs`：三楼层切换、缩略图、风险、事件卡、楼梯和手机布局。
- `node tests/escape-assets-fallback.cjs`：贴图和角色素材失败时，几何回退与选路仍可用。
- `node tests/escape-map-hittest.cjs`：三个楼层中路径、楼梯、出口与高危格的实际画布点击。
- `node tests/escape-route-ui.cjs`：本地预览、撤回、风险提示、确认和联机消息。
- `node tests/escape-dice-ui.cjs`：一至六点骰面和无障碍文本与实际结果一致。
- `node tests/escape-keyboard.cjs`：键盘选路、确认及画面重绘后的焦点保留。
- `node tests/escape-network.cjs`：模拟连接的广播快照、席位、非法动作与旧序号拒绝。此项不是两台真实设备联机测试。
- 浏览器测试需本地启动静态服务 `python -m http.server 8769 --bind 127.0.0.1`，并设置 `PLAYWRIGHT_PATH` 指向 Playwright 模块。
