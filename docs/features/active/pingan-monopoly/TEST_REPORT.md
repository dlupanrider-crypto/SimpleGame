## 三维场景补充验证

采用本地打包的 Three.js 0.160.1，测试了桌面场景渲染、三维地块点击、窄屏布局与 WebGL 不可用时的平面地图回退。本轮已人工检查[实际扩展截图](assets/office-escape-model-eval.png)，前一轮检查了三个楼层的浏览器截图。工位已采用真实三维模型，人物和部分家具仍采用面向镜头的图片，建筑主体为几何体，画面仍与概念图存在差距；本次测试不能证明两者完全一致。

在上一轮 20 个脚本全部通过后，增加三维玻璃会议室、家具和低矮边墙，并人工检查[扩展页面截图](assets/office-escape-architecture-eval.png)。本次重新运行真实扩展流程、三个楼层 33 个地图点击目标、楼层与窄屏布局、素材加载失败回退及工位模型加载测试，均通过。尚未重新执行其余未受影响的测试脚本；整体画面与概念图仍有差距。
